Le symbole †

Signale un aliment qui fait l'objet d'une note de santé — kombu, wakame, nori, edamames. La note se trouve dans la partie D du guide 1.

Par où commencer

Le guide 1, en entier, une fois. Ensuite le guide 3 avant la première épicerie. Les guides 2 et 4 se consultent, ils ne se lisent pas. Le guide 5 réunit les cibles chiffrées — protéines, calories, repas — à garder sous la main.

Le dossier

Cinq guides qui se complètent : Manger pour les principes, Recettes pour cuisiner, Supermarché pour s'approvisionner, Bouger pour l'activité, et le Plan pour chiffrer.

Avertissement
